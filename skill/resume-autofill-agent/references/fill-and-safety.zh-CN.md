# 填写与安全指南

## 字段分类

| 类别 | 示例 | 规则 |
|---|---|---|
| 已核验事实 | 学校、学位、已确认日期 | 使用最高优先级来源填写。 |
| 有证据的改写 | 项目要点、自我评价 | 可优化表达，但不得扩大事实范围。 |
| 敏感事实 | 身份证、家庭、健康、政治面貌 | 仅使用用户明确提供或授权的当前数据，并标记复核。 |
| 可选未知 | 兴趣、第二志愿 | 没有证据或价值时留空。 |
| 声明 | 诚信、亲属、利益冲突 | 必须由用户复核，不得推断。 |
| 不可逆操作 | 提交、签署、同意、撤回 | 操作前必须获得明确确认。 |

成绩、GPA、排名和成绩单遵循数据最小化：可选字段留空，不主动上传证明；只有表单明确必填、申请流程确有必要或用户明确要求时才提供。GPA 必填时只能使用已核验数值；排名必填但未知时，只能选择“未知 / 不适用 / 其他”等真实选项，不得根据 GPA 推算排名或虚构百分位。

## 岗位相关补充

按岗位相关性、证据强度、时效性和独特性筛选材料。优先使用近期强证据；旧材料只补真实空缺。技能标签必须有工作或项目证明，因果和量化表述不得超出原证据。

采用合法、真实的“强项优先”策略，不以填满所有可选字段为目标。优先展示能增强岗位匹配度的证据；允许留空时，省略较弱、重复、过时或会造成无必要敏感信息暴露的材料。不得省略必填事实或规避诚信声明。对重要的填写与省略保留简短取舍记录，注明字段、动作和理由，便于用户复核。

改写必须保持四个边界不变：

1. 主体和职责范围不变；
2. 日期和组织不变；
3. 使用的方法真实存在；
4. 结果幅度和确定性不变。

## 简历上传与解析覆盖

许多网站会解析简历并覆盖手填内容，因此：

1. 记录或截图现有值；
2. 可能触发解析时先上传简历；
3. 等待解析完成；
4. 复核身份、教育、日期和重复模块；
5. 恢复已核验的正确值；
6. 保存并在离开页面前验证。

若上传导致内容丢失，应从来源账本恢复，不依赖临时记忆。

## 作品附件流程

1. 检查岗位说明和附件字段接受的类型、大小、数量、命名规则，以及是否优先接受链接。
2. 按直接相关性、证据强度、可读性和文件大小排序。
3. 上传前检查压缩包；只在投递副本中移除无关或隐藏文件，绝不改动原件。
4. 使用不含不必要隐私的专业文件名，例如 `<project>-demo.<ext>` 或 `<project>-portfolio.zip>`。
5. 优先选择短而有代表性的演示，加已核验的公开仓库链接，避免超大的原始压缩包。
6. 仅压缩或转码投递副本，并验证媒体能播放、压缩路径清晰、文字可读。
7. 上传一次并等待完成，核对页面显示的文件名；记录申请、字段、原件、投递副本和上传结果。

作品压缩包不得夹带家庭材料、成绩单、身份证件、聊天记录、凭据、`.git` 元数据、环境变量文件或无关源文件。除非明确必填或用户要求，不上传中文、英文或中英双语成绩单。除非必要，避免文件名或媒体元数据包含私人联系方式。

## 重复模块

对教育、经历、项目、奖项和家庭信息：

- 先确认条目数量与排序；
- 除非表单明确要求其他顺序，带日期的教育、工作、实习、项目、奖项和论文按结束日期、再按开始日期从近到远倒序排列；
- 不信任简历解析产生的顺序，完成后复核页面中的实际显示顺序；
- 每次添加一条；
- 尽可能逐条保存或确认；
- 新增后重新检查全部条目，因为索引可能变化；
- 避免简历解析产生重复记录。

## 浏览器操作备用方案

按照 [browser-control.zh-CN.md](browser-control.zh-CN.md) 选择并初始化可用的控制方案。遇到定制日期控件、下拉框或富文本框时，优先依据可见标签操作，必要时使用键盘导航，并在每个异常控件操作后核对显示值。不得仅为确认保存状态而刷新页面。

所有直接控制方案都不可用时，生成逐字段填写清单，只让用户完成最少量的手动点击或敏感信息输入。不得因为扩展已安装或已启用就声称控制成功；必须通过“列出页面”或“页面快照”的成功结果确认。

交互失败时，先检查实时页面和错误状态，保留已经填写的内容，再有限次尝试更精确的定位、键盘操作、已验证的备用适配器或与网站兼容的辅助脚本等安全方案。每次异常控件操作后都要回读受影响字段。只有在仍缺少证据、需要影响正确性的选择、涉及登录或验证码，或必须由用户手动操作时才询问用户。

## 仓库贡献声明

写说明前检查压缩包和媒体文件名。仅在表单支持时添加已核验的公开仓库。不得因为仓库位于某账号或组织下，就声称学生创作了全部仓库；个人贡献必须由简历、提交记录、项目文件或用户明确确认支持。

## 完成闸门

结束前确认：

- 必填可见字段已填写，或已列为未解决；
- 简历上传状态正确，解析字段已复核；
- 重复模块没有明显重复；
- 日期和指标与来源账本一致；
- 作品附件与岗位相关，并通过隐私、格式和大小检查；
- 占位值已标记且仅适用于当前申请；
- 声明与敏感字段已标记为用户复核；
- 草稿保存状态可见或已验证；
- 未经确认没有最终提交或签署。
